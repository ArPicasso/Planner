# Атлас — бот и Mini App на Telegram Serverless

Пишешь в чат как обычно: «матрас 160, шторы в спальню, роутер; до 1 ноября подключить интернет».
Бот через Claude раскладывает это по разделам (Купить / Дела / Обсудить), а в Mini App видно всё списками
с галочками, «Беру», сроками и ценами. Общая группа с другом = общее пространство, личка с ботом = личное.

## Запуск (≈10 минут)

Нужны: Node.js 18+, бот в @BotFather с включённым Serverless, ключ Claude API (console.anthropic.com).

```bash
cd atlas-bot
npm install
npx tgcloud login          # вставь CLI-токен: @BotFather → бот → Serverless → CLI Access
npx tgcloud push           # загрузит код и Mini App, напечатает адрес https://app<id>.tgcloud.ai/
npx tgcloud migrate        # создаст таблицы в базе
```

Дальше в Telegram, строго по порядку:

1. **Напиши боту `/start` в личку.** Первый, кто это сделает, становится владельцем.
2. **Пришли `/key sk-ant-…`** — ключ Claude. Бот удалит сообщение и проверит ключ тестовым запросом.
3. **@BotFather → бот → Bot Settings → Configure Mini App → Enable Mini App**, адрес — тот, что напечатал `push`.
   Это включает ссылки «Открыть список» (`t.me/<бот>?startapp=…`).
   По желанию: `/setapp https://app<id>.tgcloud.ai/` в личке с ботом — появится кнопка «Список» в меню чата.
4. **@BotFather → бот → Bot Settings → Group Privacy → Turn off.** Иначе в группе бот видит только команды.
5. **Создай группу «Квартира» с другом и добавь туда бота.** Он предложит шаблон, жми «Дом и переезд».

Готово. Пиши в группу, друг тоже.

## Что умеет

| В чате | Что произойдёт |
|---|---|
| `матрас 160, шторы в спальню, роутер` | 3 покупки, разложены по комнатам |
| `до 1 ноября подключить интернет` | дело со сроком в «Дела» |
| `общий пылесос или каждому свой?` | вопрос в «Обсудить» |
| `беру шторы` | пункт закрепляется за тобой |
| `купил роутер 45€` | пункт закрыт, цена записана |
| `что осталось купить?` | ответ по текущему списку |
| `// просто болтаем` | бот пропускает |
| `/list` `/app` `/undo` `/help` | список текстом, приложение, отмена, справка |

Под каждым ответом бота есть «Отменить». Обычную болтовню в группе бот игнорирует.

В Mini App: экран «Сегодня» (новое от других, на мне, сроки на 2 недели), плитки пространств,
вкладки-разделы, группировка по комнатам, «Беру», карточка пункта (цена, срок, заметка), сумма «осталось / потрачено».
Поле ввода внизу работает так же, как чат: строки сразу появляются серыми, через пару секунд встают на место.
То, что добавлено из приложения в общее пространство, бот тихо дублирует в группу.

## Доступ

- Владелец — тот, кто первым написал `/start`.
- Пользоваться ботом могут владелец и участники групп, куда владелец добавил бота.
- Чужие группы бот покидает, чужим людям в личке отвечает, что бот закрытый.
- Ключ Claude хранится в базе бота (таблица `config`), в коде его нет.

## Команды владельца (в личке)

- `/key sk-ant-…` — ключ Claude.
- `/model <id>` — модель (по умолчанию `claude-haiku-5-5`: быстро и дёшево).
- `/setapp <url>` — кнопка «Список» в меню чата.

## Проверка локально

`npm test` прогоняет полный сценарий (личка, группа, Claude, «беру», «купил», отмена, все эндпоинты, доступы)
на макете SDK из `test/mock-sdk.mjs`, без сети.

После деплоя можно дёрнуть код на платформе без Telegram:

```bash
npx tgcloud run endpoints/bootstrap '{}' --ctx '{ initData: { user: { id: <твой id>, first_name: "Павел" } } }'
```

## Структура

```
tgcloud/schema.js          таблицы: config, users, spaces, members, sections, items, batches
tgcloud/lib/router.js      текст → Claude → операции → одна отменяемая пачка
tgcloud/lib/ai.js          вызов Claude API
tgcloud/lib/store.js       доступ к данным, шаблоны разделов
tgcloud/lib/views.js       проверка доступа и данные для экранов Mini App
tgcloud/handlers/          message, callback_query, my_chat_member
tgcloud/endpoints/         bootstrap, getSpace, addText, setDone, claim, editItem, deleteItem, addSection, undo
web/                       Mini App без сборки: index.html, app.js, style.css
```

## Чего пока нет

- **Утренние пинги «что на сегодня»**: в документации Serverless нет планировщика задач. Когда появится, это один хендлер.
- **Голосовые**: Claude API не принимает аудио, нужен отдельный сервис распознавания.
- **Майндкарта** из первого прототипа: следующий шаг, как обзорный экран поверх разделов.
